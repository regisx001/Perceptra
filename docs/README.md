## Important project constraints

- The image-analysis REST API must use Python, Flask, and Flask-RESTful.
- The assignment does not mandate a database engine or frontend framework.
- Group 13 is assigned Feature Relevance Estimation.
- The exact mathematical method must follow the scientific paper supplied by the instructor.
- The GHIM-10K dataset is not included in this documentation package.
